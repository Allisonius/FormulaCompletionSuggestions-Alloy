# Alloy Language Extension

Alloy Language Extension is a Visual Studio Code extension that adds rich programming features for the modeling language Alloy. This version of the extension is a prototype and is not yet ready for production use. This extension is part of the Alloy Live Programming project, which aims to provide a live programming environment for the Alloy modeling language.

# Features

Alloy is a declarative language for modeling systems and exploring their properties. The Alloy Language Extension brings essential Alloy tooling directly into Visual Studio Code, making it easier to write, analyze, and experiment with Alloy models. This extension provides the following features:

- Syntax highlighting
- Code completion
- Error checking
- Code Lens to run commands
